# Lessons

Keep entries short and durable. Add a new line only when a mistake or useful rule is likely to recur.

- Inspect the real CSS/JS before calling an HTML state a bug.
- Separate confirmed facts from inference.
- Never remove deployment/config files just because they look unused.
- Prefer small, reversible portfolio edits over broad rewrites.
- Keep human-made and AI-assisted provenance labels accurate.
